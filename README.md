# Travel · 旅行计划

## 广西国庆七天情侣自驾 · 2026.10.01—10.07

深圳出发并返回，以德天瀑布、通灵大峡谷和靖西鹅泉为主，每天最多安排一个主要景区，靖西连住两晚，连锁酒店优先。

- [详细文字版计划](plans/guangxi-2026.md)
- [网页版文件](guangxi-2026.html)
- [GitHub Pages 阅读入口](https://jinnafu.github.io/travel/guangxi-2026.html)（仓库启用 Pages 并完成部署后可用）

| 日期 | 行程 | 住宿 |
| --- | --- | --- |
| 10/1 | 深圳 → 玉林，交通日 | 玉林 |
| 10/2 | 玉林 → 大新县城，下午休息 | 大新 |
| 10/3 | 德天瀑布 → 靖西 | 靖西 |

| 10/7 | 梧州 → 深圳 | 回家 |

全程约 2200—2400 公里，两人费用估算 ¥6500—11000，未实际预订。具体票价、房价、余票、天气与车程需出发前确认。

网页版支持按天筛选、折叠行程、字号切换、本机预约待办记录，以及打印 / 保存 PDF。景区及酒店提供高德地点搜索入口，确认目的地后可在地图中开启驾车导航。

## 本地查看

直接用浏览器打开 `guangxi-2026.html`，无需安装依赖或构建。样式和脚本位于 `assets/guangxi.css`、`assets/guangxi.js`。打印时会展开全部七天，即使当前只筛选了一天。

广西页面的待办和字号只保存在当前浏览器，使用独立的 `travel_guangxi_2026_preferences_v1` 存储键，不接入青甘页面的家庭云同步。
